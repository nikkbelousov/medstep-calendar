# Taper Calendar

Локальное React-приложение для отслеживания одного настраиваемого плана постепенного снижения.

## Статус

Phase 2: один активный план можно настроить по дате старта, препарату, дозе/времени, поддерживающим препаратам, симптомам и схеме.

Новый ключ хранения: `taper-calendar-v2`.

Старый ключ `omez-taper-calendar-v1` читается только для миграции существующих отметок и не удаляется.

## Запуск

```powershell
pnpm install
pnpm dev
```

Сборка:

```powershell
pnpm build
```

## Медицинское ограничение

Это приложение - личный трекер согласованного плана. Оно не предоставляет медицинские советы, диагнозы или рекомендации по лечению. Изменения лекарств нужно обсуждать с квалифицированным медицинским специалистом.
