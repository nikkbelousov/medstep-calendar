# Календарь мягкого снижения Омеза

Локальное React-приложение для отслеживания фиксированного прототипа календаря снижения Омеза.

## Запуск

```powershell
pnpm install
pnpm dev
```

Сборка:

```powershell
pnpm build
```

## Phase 1

Цель текущей версии - восстановить прототип из `src/reference/omez_taper_calendar_app.jsx` как рабочее Vite + React + TypeScript + Tailwind приложение.

Данные сохраняются только в браузере через `localStorage` с ключом `omez-taper-calendar-v1`.
