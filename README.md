# Taper Calendar

Локальное React-приложение для отслеживания одного пользовательского плана постепенного снижения препарата.

## Возможности

- Настраиваемая дата старта.
- Настраиваемые название препарата, доза и время.
- Названия поддержки, резерва и симптомов задаются пользователем.
- Пресеты схем: базовый 8-недельный план, `6/1`, `5/2`, через день, 1 раз в 3 дня, по требованию.
- Собственная повторяющаяся последовательность дней.
- Отметки по дням: выполнено, поддержка, резерв, симптомы, заметка.
- Локализация интерфейса: русский, английский, армянский.
- Локальное хранение данных через `localStorage`.
- Автоматическая миграция старых локальных отметок, если они есть в браузере.
- Базовая PWA-поддержка: manifest, app icon, service worker, standalone mode.

## Privacy

Данные не отправляются на сервер и не синхронизируются с облаком. Всё хранится локально в браузере пользователя.

При очистке данных браузера записи приложения могут быть удалены. Export/import JSON пока не реализован.

## Медицинское ограничение

Это приложение — личный трекер заданного пользователем или согласованного с врачом плана. Оно не предоставляет медицинские советы, диагнозы или рекомендации по лечению. Изменения лекарств, дозировок и схем нужно обсуждать с квалифицированным медицинским специалистом.

English disclaimer:

This app is a personal tracking tool. It does not provide medical advice, diagnosis, or treatment recommendations. Medication changes should be discussed with a qualified healthcare professional.

## Запуск

```powershell
pnpm install
pnpm dev
```

Локальный адрес по умолчанию:

```text
http://127.0.0.1:5173/
```

## Проверка

Тесты:

```powershell
pnpm test
```

Production build:

```powershell
pnpm build
```

Production preview:

```powershell
pnpm preview
```

PWA-проверку лучше делать через `pnpm build` + `pnpm preview`, потому что service worker регистрируется только в production mode.
