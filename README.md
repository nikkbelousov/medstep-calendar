# Календарь мягкого снижения Омеза

Локальное React-приложение для отслеживания фиксированного прототипа календаря снижения Омеза.

## Статус

Phase 1 завершена: прототип восстановлен как Vite + React + TypeScript + Tailwind приложение, сборка проходит, данные сохраняются в `localStorage`.

Ключ хранения: `omez-taper-calendar-v1`.

## Запуск

```powershell
pnpm install
pnpm dev
```

Сборка:

```powershell
pnpm build
```
