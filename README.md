# Taper Calendar

Локальное React-приложение для отслеживания одного настраиваемого плана постепенного снижения.

## Статус

Phase 2: один активный план можно настроить по дате старта, препарату, дозе/времени, поддерживающим препаратам, симптомам, схеме и языку интерфейса.

Поддерживаемые языки интерфейса: русский, английский, армянский.

Данные сохраняются локально в браузере через `localStorage`.

Старые локальные отметки из ранней версии приложения мигрируются автоматически, если они есть в браузере.

## Запуск

```powershell
pnpm install
pnpm dev
```

Сборка:

```powershell
pnpm build
```

Тесты:

```powershell
pnpm test
```

## Медицинское ограничение

Это приложение - личный трекер согласованного плана. Оно не предоставляет медицинские советы, диагнозы или рекомендации по лечению. Изменения лекарств нужно обсуждать с квалифицированным медицинским специалистом.
